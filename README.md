# EXM Wallet · фронтенд для дизайна

Интерфейс EXM на React, TypeScript и Vite. Проект запускается локально на фикстурах. API-запросы обслуживает тот же Vite, который отдаёт страницу.

## Запуск

Понадобится Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте [экран входа](http://127.0.0.1:5178/) или [тестовый портфель с Ethereum, Solana и Bitcoin](http://127.0.0.1:5178/?watch=0x1111111111111111111111111111111111111111,HAgk14JpMQLgt6rVgv7cBQFJWFto5Dqxi472uT3DKpqk,bc1qcr8te4kr609gcawutmrza0j4xv80jy8z306fyu). Портфель открывает вкладки Главная, Обмен, Рынок и История. Данные фикстур привязаны к локальному профилю браузера. Для повторного прохождения входа откройте новый профиль или очистите данные сайта `127.0.0.1:5178`.

| Команда | Что открывает |
| --- | --- |
| `npm run dev` | Портфель с балансом, история Ethereum, токены, графики, котировки и получение |
| `npm run dev:empty` | Те же экраны с нулевыми остатками и пустой историей |
| `npm run dev:offline` | Состояния недоступного провайдера |
| `npm run dev:review` | Форма отправки Ethereum и экран проверки перевода с локальным тестовым кошельком |
| `npm run build && npm run preview` | Собранный фронтенд с теми же моками на порту 4188 |

Для просмотра формы отправки запустите `dev:review` и создайте или импортируйте отдельный тестовый кошелёк. Например, для импорта используйте публичную фразу BIP-39 из одиннадцати слов `abandon` и последнего слова `about`. Задайте локальный тестовый пароль от 15 символов. Введите любую тестовую сумму и получателя `0x2222222222222222222222222222222222222222`. Подтверждение остановится на заглушке подписи. Для сценариев входа используйте только отдельные тестовые фразы.

## Где менять интерфейс

| Путь | Содержимое |
| --- | --- |
| `src/app/App.tsx` | Вход, оболочка и навигация |
| `src/app/home`, `src/app/onboarding` | Главная, настройки и авторизация |
| `src/app/screens`, `src/app/history`, `src/app/tokens` | Получение, отправка, история и активы |
| `src/app/market`, `src/app/swap` | Рынок, графики и обмен |
| `src/app/palette.css`, `src/app/wallet.css` | Токены темы и стили кошелька |
| `src/app/art` | Кристалл, аватары и иллюстрации |
| `mocks/wallet.json` | Балансы в минимальных единицах, цены и токены |
| `mocks/routes.mjs` | Формы ответов, история и графики |
| `src/lib/api/backend.ts` | Перевод адресов клиентских API в пути `/api/…` для последующей стыковки |

Фикстуры возвращают только локальные данные. Суммы, курсы, хэши и результаты истории синтетические. На этапе стыковки замените обработчики в `mocks/` сервисом с теми же маршрутами `/api/rpc/`, `/api/data/` и `/api/portfolio/`, сохранив клиентские типы ответов.
